# Mini Project #2 — Proposal 

## What I'm building
A Fortune Teller web app where users ask life questions and receive dramatic, mysterious fortunes from an all-knowing oracle.

## Who it's for / Why
Anyone who wants a fun, interactive experience — whether killing time, looking for laughs, or pretending to glimpse their future. It's replayable, shareable, and genuinely entertaining.

## Core Features
1. User enters their name and selects a question category (Love, Career, Destiny, Warning)
2. Click the crystal ball to consult the oracle — fortune reveals with a typewriter animation
3. Fortunes are randomized from a curated pool based on category
4. Session history tracks how many times you've asked and shows past fortunes
5. "Ask Again" button resets the input for a new question without refreshing the page

## What I don't know yet
- How to implement a typewriter text animation in JavaScript
- How to randomize and pool fortunes by category
- How to store and display session history dynamically in the DOM
